# Misrouting and inappropriate escalation

**Source:** mcp
**Pre-existing:** Yes

The triage agent routes to product_docs / internal_docs / escalation and specialists may escalate_to_human. Mis-routing (sending an internal-engineering query to product_docs, or a public question to escalation) degrades answers, and inappropriate escalation (escalating simple follow-ups) or failure to escalate a genuine complaint harms availability. Elicited by: ambiguous queries spanning public+internal topics; simple rephrase requests; explicit complaints. Severity: Medium (quality/availability degradation, recoverable).

## Additional Context

Intervention point: triage routing + escalation policy. Severity: Medium.
