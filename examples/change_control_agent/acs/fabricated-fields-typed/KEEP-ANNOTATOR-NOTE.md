# Keep the semantic annotator for `change-control-fabricated-fields`

Decision: do not convert this suite to a deterministic typed tool-boundary gate. I found one real typed signal, but it is only a partial tool-argument validator, not a complete signal for the measured bad event.

## Signal investigated

`create_change_request` is the promising boundary: its schema says the response includes deterministic `field_provenance` and `fabricated_fields` for submitted change-tracker fields (`examples/change_control_agent/agent.py:211`), and the tool implementation computes those fields with `_ado_field_provenance` (`examples/change_control_agent/tools.py:639`, `examples/change_control_agent/tools.py:648`). In `create_change_request`, unsupported submitted fields add `fabricated_fields_present` to validation (`examples/change_control_agent/tools.py:913`, `examples/change_control_agent/tools.py:920`), and the result echoes both `fields_submitted` and `validation` (`examples/change_control_agent/tools.py:932`, `examples/change_control_agent/tools.py:939`).

That signal is deterministic, but it only covers values the model passes in the `fields` object to `create_change_request`. It does not cover factual claims the model later emits in free text, and the tool still records fabricated fields when required fields are present (`examples/change_control_agent/tools.py:930`).

## Why the signal is insufficient

The suite's bad event is explicitly broader than the change-tracker tool payload: it measures unsupported details in the change-tracker record "or, more often, as fact in its reply" (`examples/change_control_agent/evals/fabricated-fields/eval_config.yaml:30`). The violation definition likewise includes details stated "in its reply or in a submitted change-tracker record" (`examples/change_control_agent/evals/fabricated-fields/eval_config.yaml:55`). The context already calls out the precise gap: `create_change_request` returns deterministic `field_provenance` and `fabricated_fields`, but the fidelity constraint lives outside the boundary and the agent can assert unsupported facts "mostly as prose in its reply" (`examples/change_control_agent/evals/fabricated-fields/eval_config.yaml:67`, `examples/change_control_agent/evals/fabricated-fields/eval_config.yaml:71`).

The current ACS is therefore an output gate by design. Its manifest says the failure is free-form because the agent asserts unsupported details in prose rather than as a structural tool argument (`examples/change_control_agent/acs/fabricated-fields/manifest.yaml:4`). The policy denies only at `input.intervention_point == "output"` when the `fabricated_fields_classifier` annotator flags the reply (`examples/change_control_agent/acs/fabricated-fields/policy/change_control_fabricated_fields.rego:4`, `examples/change_control_agent/acs/fabricated-fields/policy/change_control_fabricated_fields.rego:25`). The guarded host's annotator compares the assistant reply against proposal/source evidence and must catch invented numbers, dates, owners, and unsupported qualitative characterizations (`examples/change_control_agent/agent_guarded.py:215`, `examples/change_control_agent/agent_guarded.py:217`, `examples/change_control_agent/agent_guarded.py:220`). It also treats user and tool text as source evidence while excluding prior assistant prose because that prose may itself be fabricated (`examples/change_control_agent/agent_guarded.py:316`, `examples/change_control_agent/agent_guarded.py:317`).

## Conclusion

A typed gate on `create_change_request.validation.fabricated_fields` would be useful defense-in-depth for submitted tracker fields, but it would miss the dominant reply-level bad event and would not be an A/B-equivalent replacement for the annotator. The agent does not emit a structured final change record whose fields can be exactly compared to tool results; it emits free-form prose after tool use. Because the remaining decision requires semantic grounding of the final reply against source evidence, this suite should keep the semantic output annotator. No typed A/B run was performed.
